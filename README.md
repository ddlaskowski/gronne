# Grønne Mur og Flis AS

Premium architectural website for Grønne Mur og Flis AS,
a Norwegian craftsmanship company based in Oslo.

## About

A modern, responsive website showcasing professional
craftsmanship in tiling, masonry, bathrooms, and concrete work.

The design combines Scandinavian minimalism,
architectural editorial layouts, and subtle motion design.

## Technology

- Next.js
- TypeScript
- Tailwind CSS
- GSAP (planned)
